# Experiments

Use this directory for exploratory work: paper reproductions, ablations,
system prototypes, and quick tests that are not yet stable enough for
`src/`.

Each experiment should have a short note covering:

- hypothesis;
- setup;
- command or entry point;
- result;
- next decision.

When an experiment becomes reusable, move the stable code into `src/`
and keep the result writeup here or in `notes/`.
